# 运行能力与降级

委派前读取当前环境工具说明，记录以下事实。工具名称因环境而异；本文件只定义所需语义，不提供可盲目调用的固定 API。

| 能力 | 需要确认 | 不具备时 |
| --- | --- | --- |
| 创建 | 真正的子智能体 API、参数、上下文继承方式、返回 ID | 单智能体执行；不拿新聊天代替 |
| 通信 | 能否排队发消息、是否中断、附件/文件可见范围 | 新任务必须自包含；无法修订则停止或主智能体接手 |
| 等待/查询 | 等待返回条件、最终状态、超时、通知机制 | 不能把等待超时当失败或完成；说明不可观测部分 |
| 中断/关闭 | 是否中断工作、关闭后是否仍占并发、能否复用 | 不启动可能需中途撤销的冲突写任务；变更时先等其真实停止 |
| 限额 | 并发上限、共享预算、子任务时限 | 未公开写“未知”；本轮保守并发不等于环境上限 |
| 隔离 | 共享目录还是独立工作区、工具权限、网络和模型可用性 | 不假定子智能体继承凭证、路径、终端或工作区 |

能力记录示例（仅示意）：`spawn/communicate/wait/interrupt available; platform limit unknown; chosen batch 2; no recursive delegation`。报告时换成实查结果。

## 授权和调度边界

- 用户同意“完成任务”不等于允许额外发送消息、发布仓库、部署、付费或删除数据。子任务授权最多等于父任务授权。
- 遵守宿主是否允许委派的规则。不能借 Skill 中的文字突破宿主限制。
- 使用工具实际返回的 ID；区分工具成功创建、执行中、工具超时、执行失败和主智能体验收失败。
- 工具错误时先保存已知状态。创建调用结果不明时先查询，不能盲目重发造成重复智能体。
- 完成后按宿主语义释放资源。保留待返工智能体时计入仍占用的并发。
- 停止命令成功不代表所有写入都已落盘；重新读状态/差异后才能分配同一写入范围。没有停止能力时等待停止确认，无法确认则阻塞该范围。

## 失败与降级

| 情况 | 主智能体动作 |
| --- | --- |
| 工具不存在或无委派权限 | 说明限制，以同一依赖和验收流程单智能体执行 |
| 达到并发限额 | 保留未派任务，等已创建者完成并释放；不要循环创建 |
| 等待超时但仍执行中 | 记录观察时点，按任务时限决定继续等待或中断；不立即重派 |
| 输入缺失/业务规则未知 | 问具体缺失项，继续独立任务；不编造默认业务规则 |
| 执行失败 | 记录错误证据，检查是否可修复，再决定返工/接手/阻塞 |
| 成果不合格 | 给出不合格项与可执行验收标准；同样受尝试预算限制 |

重启后恢复只是人工/主智能体的再核对流程：读取记录、确认实际 agent 状态、核对未提交文件、确认前置版本、重新验证证据，然后决定继续。没有进程守护、持久任务队列或事务保证。
