## 接口与数据

接口为 `pagination.paginate(records, page, page_size)`，实现位置约定为 `pagination.py`，仅使用 Python 标准库。

`records` 是记录列表，每条记录为含整数 `id` 的字典，可带任意额外字段。`page` 从 1 开始，`page_size` 为 1～100 的整数。`id` 可以为负数，也可以重复。

返回值为记录列表，记录的额外字段完整保留。返回的列表独立于原列表；记录字典可复用原对象，不要求深拷贝。

## 排序与分页

1. 使用 `sorted(records, key=lambda record: record["id"])` 获得按 `id` 升序排列的新列表。
2. 计算起点 `start = (page - 1) * page_size`，终点 `end = start + page_size`。
3. 返回排序后列表的 `[start:end]` 切片。

Python 的稳定排序使相同 `id` 的记录保持其在原输入中的相对顺序。先排序后切片，确保每页对应完整排序结果中的连续区间。

排序不使用原地 `list.sort()`，处理过程中不更新记录字典，不改变原列表顺序、长度、元素引用或字段内容。单次调用时间复杂度为 `O(n log n)`，额外空间为 `O(n)`。

## 边界与示例

- 空记录列表返回空列表。
- `page=1` 从排序结果的第一个元素开始。
- `page_size=1` 每页至多一条记录；`page_size=100` 每页至多一百条记录。
- 最后一页不足 `page_size` 条时，返回剩余记录。
- 页码超出已有页数时，切片返回空列表。
- 负数 `id` 与其他整数一起按数值升序排列；重复 `id` 不去重。
- 当输入包含 `id` 为 1～5 的记录时，`page=2, page_size=2` 返回 `id` 为 3、4 的记录，且顺序为 3、4。
